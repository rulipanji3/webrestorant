Class Diagram

Menggambarkan struktur entitas model data Eloquent, atribut, method, serta relasi asosiasi sistem.

classDiagram class Category { +int id +string name +string slug +timestamp created_at +timestamp updated_at +booted() void +menuItems() HasMany } class MenuItem { +int id +int category_id +string name +string description +int price +string image_url +string image +boolean is_available +timestamp created_at +timestamp updated_at +category() BelongsTo +imageSrc() string +casts() array } class Order { +int id +string reference_code +string customer_name +string customer_phone +string service_type +string status +int total +timestamp created_at +timestamp updated_at +items() HasMany +serviceLabel(type) string } class OrderItem { +int id +int order_id +string product_id +string name +int price +int quantity +timestamp created_at +timestamp updated_at +order() BelongsTo } class Booking { +int id +string name +string phone +date date +string time +int guests +string table_type +string notes +string status +timestamp created_at +timestamp updated_at +casts() array } class CheckoutController { +index(Request) View +store(Request) JsonResponse +destroy(Order) RedirectResponse +destroyAll() RedirectResponse } class MenuItemController { +index(Request) View +store(Request) RedirectResponse +edit(MenuItem) View +update(Request, MenuItem) RedirectResponse +destroy(MenuItem) RedirectResponse +availableIds() JsonResponse +availability() View +toggleAvailability(MenuItem, Request) Response } Category "1" --> "0..*" MenuItem : hasMany Order "1" *-- "1..*" OrderItem : composition MenuItem "0..1" ..> "0..*" OrderItem : referenced by CheckoutController ..> Order : manages CheckoutController ..> OrderItem : creates MenuItemController ..> MenuItem : manages

Kardinalitas & Relasi:

  • Category ke MenuItem: 1 ke Banyak (*One-to-Many*).
  • Order ke OrderItem: Komposisi (*Composition*), jika Order dihapus maka OrderItem yang terasosiasi otomatis ikut terhapus (*cascade delete*).
